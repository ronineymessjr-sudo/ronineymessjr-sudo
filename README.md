## 关于我 / About

我关注 **AI 应用、Agent 工作流与摄影创作**，持续把具体场景里的重复劳动，整理成可以使用、验证和迭代的软件。

对我来说，产品不止是一个生成结果的按钮：它还需要清楚的交互、可追溯的依据，以及从接口、数据到部署的完整链路。摄影和视觉审美是我的创作兴趣，也是许多产品想法的起点。

- **AI × 工作流**：探索 Agent、MCP、检索与证据驱动的内容生成，让 AI 能力进入实际任务。
- **创作 × 工具**：围绕参考图、拍摄方案、分镜和创作资源，构建更顺手的摄影工作台。
- **工程 × 可靠性**：重视权限边界、数据核验、自动化测试、持续交付与上线后的可观测性。

## 我的构建方式 / How I build

**从具体问题出发。** 先理解使用场景，再决定是否需要 AI、自动化或一个更简单的界面。

**让结果有依据。** 关注来源、证据、人工确认和可复现的检查，不把演示数据当作真实业务结果。

**把体验和交付一起考虑。** 好用的交互与稳定的接口同样重要；上线后也继续观察问题、收集反馈、逐步打磨。
